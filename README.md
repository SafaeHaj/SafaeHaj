# Hi there!

I'm a final-year Computer Engineering student at **UM6P**, focused on **data engineering, distributed systems, and AI-driven data pipelines**.

My recent work revolves around building systems that turn large, heterogeneous datasets into structured and usable information — from research-paper processing pipelines and knowledge graphs to distributed storage systems and predictive models.

## Featured Projects

### Functional Ingredient Research & Analysis Platform
AI-powered platform for extracting, structuring, and analyzing experimental data from scientific literature.

- Built an end-to-end document processing pipeline for **181 research papers**, extracting **39K+ observations** from tables and figures.
- Designed a structured evidence layer linking extracted data back to document pages and source elements.
- Implemented table and chart extraction using **Docling** and **PP-Chart2Table**.
- Developed controlled vocabularies and normalization pipelines for ingredients, doses, indicators, and experimental conditions.
- Built predictive models using **LightGBM** for shelf-life classification and time-to-failure estimation.
- Containerized the system with **Docker**, integrating **FastAPI, Celery, Redis, and PostgreSQL**.

### Financial News GraphRAG
Knowledge-graph-based pipeline for analyzing and retrieving information from financial news.

- Processed and structured **5,000 financial articles** into an entity-aware knowledge graph.
- Fine-tuned **Llama 3.2 3B** for structured knowledge-graph extraction.
- Integrated **Mistral NeMo 12B** for multi-source retrieval and synthesis.
- Used a domain-pretrained **Financial BERT** encoder for domain-specific representations.
- Designed entity-aware retrieval and reasoning workflows for financial information.

### Kademlia-Based Distributed Hash Table
Distributed systems project implementing a decentralized key-value lookup network.

- Implemented the **Kademlia DHT** protocol and its routing mechanisms.
- Explored distributed node discovery, key routing, replication, and fault tolerance.
- Developed the system in **Go**, focusing on concurrency and distributed communication.

### R&D Document Intelligence Pipeline
Automated pipeline for evaluating and processing technical and research documents.

- Built modular document-processing workflows combining **LLMs, structured extraction, and retrieval**.
- Designed agentic workflows with **LangGraph** for document evaluation and reasoning.
- Integrated multiple LLM providers and local models depending on task requirements.
- Focused on reliable structured outputs rather than direct text generation.

### Graphics, Signal Processing & Machine Learning
Collection of projects exploring high-dimensional data visualization and machine learning.

- Worked with **1D, 2D, and 3D signal visualization** and movement-tracking dashboards.
- Compared dimensionality-reduction techniques including **PCA, Kernel PCA, t-SNE, and UMAP**.
- Experimented with image processing and tree-based machine-learning models.
- Explored synthetic data generation using **CTGAN, TVAE, and CopulaGAN**.
