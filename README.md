# Hi there! 👋

Welcome to my GitHub! I'm passionate about software development, with a focus on creating efficient and well-structured systems. My projects span various domains, from algorithmic challenges to full-stack web development and version control systems.

## 🚀 Projects
- **Adaptive Learning System:** With my partner Malak Kably, we researched and developped a comprehensive backend for the startup Ederest's adaptive learning system, following BKT and IRT models which adjust the learning material according to the user's progress.

- **Graphics and Interactive Techniques Mini-Projects:** Together with Yahya Mansoub, I had the chance to work on signal visualization (1D, 2D, and 3D) and test different dimensionality reduction techniques such as PCA, t-SNE and UMAP, as well as design dashboards for 3D movement tracking. In addition to this we also worked on different image processing techniques, especially ML driven ones using tree-based models.
  
- **LDC Competition:** In this edition we collaborated with the SAP+D, ENA Rabat and 1337 schools to create a self-sustainable smart residence. My task consisted of creating and managing the backend (in python using Flask with Postgres database and Docker for portability) along with creating the necessary AI models, or in some cases adapting existing models like YOLO according to our needs, to support the system.
   
- **Jobsteer:** A comprehensive web platform designed to streamline the job search process by connecting job seekers with potential employers. It features advanced filtering options, a personalized job recommendation system, and user-friendly dashboards for both candidates and recruiters.

- **UM6P CS IntroDB Project 2:** A collaborative database project focused on implementing advanced database concepts, including relational schema design, SQL queries, data normalization, and performance optimization via testing index queries. My first introduction to developping an app from start to finish.
